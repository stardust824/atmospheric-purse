This is a purse that is able to connect to the internet and tell you the weather. It is equipped with a Raspberry Pi Pico W, a LCD display, and a buzzer. The Raspberry Pi Pico W connects to the internet via WiFi and requests weather data from NOAA. Then, the high and low of the day are displayed on the LCD screen. The purse comes equipped with a button that, when pressed, plays a song based on the weather. This was done with midi files. 

Note: this repo only contains the code. A tutorial on how to create the product can be found here: https://docs.google.com/document/d/1jf7MM2Wbuzf2DQz3EgWveOHBryGOWpgFM6y6zp6jhQM/edit?usp=sharing
